# 💖 Happy Birthday Bestie Website

A beautiful, animated multi-page birthday website for your girl BFF.

## Features
- **Splash screen** with gift-opening animation
- **6 unique pages** with smooth transitions
- **Glassmorphism + neon UI** design
- **Floating hearts** & particle background
- **Confetti explosions** everywhere
- **Bottom navigation** (mobile-first)
- Interactive cake (blow the candle)
- Virtual hug counter
- Birthday song player
- Fully responsive

## Pages
1. **Home** – Hero + heartfelt quote
2. **Her** – 6 reasons why she’s amazing
3. **Memories** – Beautiful timeline
4. **Wishes** – Special birthday letter + mini wishes
5. **Fun** – Interactive cake, song & hug counter
6. **Love** – Final emotional message + big celebrate button

## How to Open
1. Open `index.html` in any modern browser (Chrome, Safari, Edge, Firefox)
2. Or host the whole `birthday-site` folder on Netlify / Vercel / GitHub Pages

## Customize
- Change texts in `index.html`
- Colors are in `css/style.css` under `:root`
- Add real photos later if you want (just replace the emoji sections)
